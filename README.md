# נגריית אלון — עמוד תדמית

עמוד תדמית של עמוד אחד עבור "נגריית אלון", נגר עצמאי מפרדס חנה
המייצר רהיטים בהזמנה אישית.

## דרישות טכניות

- עמוד אחד ב-HTML ו-CSS רגילים בלבד.
- קובץ CSS נפרד מקובץ ה-HTML.
- ללא ספריות חיצוניות.
- ללא frameworks וללא כלי build.
- אתר קל ומהיר, עם דגש על גלישה מהטלפון (mobile-first).
- בהמשך: טופס יצירת קשר שמתחבר ל-webhook של n8n.
- פריסה (deploy) בהמשך ל-Vercel דרך GitHub.

## סטטוס

אתחול הפרויקט וסביבת ניהול הגרסאות. האתר עצמו טרם נבנה.
